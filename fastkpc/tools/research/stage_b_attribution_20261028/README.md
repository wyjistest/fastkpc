# L2/L3 Stage B attribution

Diagnostic only. The accepted native and all production sources/defaults stay
unchanged. This is not an optimization, performance promotion or L8 reopening.

Bind native `e8c39703f01e09260d330167b49267c295aa2221167d5248d0980a97c80ca045`
and the 103 inputs in the L3 runtime build receipt. Use GPU1 exclusively, both
GPUs otherwise idle, CPU affinity 0–19, CUDA connections 32 and one math thread.
Preserve every attempt and stop only our process if external GPU work appears.

1. A host-only interposer captures all L2/L3 production residual bytes, original
   cohorts, ordered keys, rank/route/info and SHA-256 of each completed component's
   three stored fields. It forwards all numerical work to the unchanged native.
   Extra diagnostic D2H and hashing are explicitly outside Stage B timing and
   cannot be mistaken for a zero-D2H diagnostic or performance result. The full
   captured skeleton must pass the existing 240,498-CI/pMax, graph/RNG, authority,
   resource and capacity gates against the accepted ON3 receipt.
2. Replay both complete captured levels through the native cache API: n351,
   numCol35, original target order/cohorts, 11 GiB cache, eight retained dense
   lanes, ten structured contexts of width64, and original wave joins. L2 has
   49,919 components / 78 waves, L3 54,878 / 86. Compare every three-field hash;
   require zero dense fallback and closed tracked resources. No CPU numerical
   producer. Prepared optimizer workspaces and intervening CI consumers are
   absent, so this is a Stage B replay, not full-method capacity/performance.
3. Three fresh unprofiled replays establish only diagnostic timing variability.
   A separate replay records CUPTI concurrent kernels, runtime/driver APIs,
   memcpy, memset and synchronization with timestamps, byte counts, streams and
   correlation IDs. Require zero dropped/invalid records. Analyze interval
   unions, not sums of concurrent lane durations. Report first/middle/tail waves
   and full-level boundaries; no-kernel and no-recorded-device-activity gaps are
   descriptive, not removable time or measured SM occupancy.
4. NCU 2024.2.1 exists but RmProfilingAdminOnly=1 and the current user has no
   CAP_SYS_ADMIN/noninteractive sudo. Record hardware occupancy/stall counters
   as unavailable; do not change driver policy. Future per-kernel replay is
   isolated evidence, not production concurrency. Range/app-range metrics must
   be qualified separately. Profiler timings never enter accepted medians.

The predeclared diagnostic success is authenticated replay identity plus a
complete activity ledger. There is no speedup gate and no kernel change.
Tools/build/protocol and source hashes are sealed before capture; amendments
retain failed evidence. See `CORRECTIONS.md` for the original L2 wave-count typo.
Run `build.py ARTIFACT_DIR`, then `campaign.py ARTIFACT_DIR`, then
`analyze.py ARTIFACT_DIR` from the repo. `archive.py` closes the recorded attempt3
and preserved failed attempts under their common artifact directory.
