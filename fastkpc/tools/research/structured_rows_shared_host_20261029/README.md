# Structured row-only: shared-host development supplement

The user authorized this separate supplement while GPU0 is occupied. It does
not replace, edit, or satisfy the previously declared two-idle-GPU campaign
under `structured_rows_20261029`. Neither native is installed by these tools.

Use the already qualified full-build parent (OFF) and row-only native (ON).
Both have the build-entry fix, postback and work-pair enabled, the same
lanes/slots, fresh R processes and dataset-specific caches, physical GPU1,
CPU affinity 0–19 and one math-library thread. No production source changes.

Before the first timing, freeze the original sequence and thresholds:

- OFF1, ON1, ON2, OFF2, OFF3, ON3; retain every completed run.
- Every canonical numerical, order, graph, RNG, authority and resource gate.
- Exactly 630,789,120 bytes less structured pool storage at every level,
  unchanged solver storage, and at least 600 MiB improvement at each paired
  L3/L4/L6 minimum-free checkpoint.
- Observed outer non-regression: ON/OFF median <= 1.02 and each pair <= 1.05.
- Observed speed threshold: median <= 0.98 and all three pairs faster.

The thresholds are copied and authenticated against the original pending
protocol. Their outcome is explicitly limited to shared-host observations;
it is not isolated acceptance, a new accepted median, or promotion evidence.
Do not retry or drop a completed run because GPU0 load or timing is unfavorable.
An external GPU1 process invalidates the run and stops only our process group.

Record both GPUs every 200 ms (utilization, memory, power, clock, temperature),
and CPU counters, load, memory, pressure and GPU-process CPU/affinity data about
every 3 seconds. Preserve raw samples. Summaries use the skeleton's compute
window, whose timestamps are recorded outside the original timer. These are
samples, not proof of instantaneous peaks or absence of host contention.

`canonical_shared.R` reuses the exact canonical expressions and gates. It only
changes the evidence label and adds timestamps outside the timed computation;
the effective expression vector and transformation receipt are saved. Source,
native, runner, inputs, references and protocol identities are checked before
and after every run. Artifacts and comparisons remain outside the timer.
